# Expense Tracker

Автор: зубаиров кирилл владимирович

## Описание программы

Это графическое приложение для отслеживания личных расходов. Пользователь может добавлять расходы с указанием суммы, категории и даты. Можно фильтровать расходы по категории и диапазону дат, а также видеть общую сумму за выбранный период. Все данные сохраняются в JSON-файл, что обеспечивает их сохранность при закрытии программы.

## Как использовать

1. Запустите программу.
2. Введите сумму, категорию, дату (в формате ГГГГ-ММ-ДД).
3. Нажмите "Добавить расход" для сохранения записи.
4. Используйте фильтры для просмотра по категории или диапазону дат.
5. Для сброса фильтров нажмите "Сбросить".
6. Все данные автоматически сохраняются в файл `expenses.json`.

## Примеры использования

- Добавление расхода:
  - Сумма: 150
  - Категория: Еда
  - Дата: 2024-04-15

- Фильтрация по категории "Транспорт" или по дате с 2024-04-01 по 2024-04-20.
